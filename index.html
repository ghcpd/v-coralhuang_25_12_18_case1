Usage Guide

Search: Type keywords to filter tasks. Matching terms are highlighted in titles.

Filter & sort: Use the status filter and click table headers to sort. Click again to cycle order.

Pagination: Use page controls and change page size to navigate results.

Inline updates: Click the status chip in a row to advance it (TODO → IN_PROGRESS → DONE). Updates are applied inline with feedback.
