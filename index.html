Usage guide

Search: type keywords in the search box; matching words are highlighted in titles.

Filter & sort: use the status menu and click column headers to cycle sorting (asc → desc → none).

Pagination: change page size or use Prev / Next to navigate pages.

Inline updates: click the status pill to advance a task (TODO → IN_PROGRESS → DONE). Updates show row-level loading and brief success highlights.

Reset
clears filters, sorting, and pagination
Refresh
re-fetches mock data (with simulated delay)

This guide is persistent and responsive — it stays visible to help you explore the UI.
