Quick Guide

Key interactions for the Task Dashboard — kept brief for quick reference.

  • Search: Type in the search box to filter titles. Matches are highlighted.
  • Filter: Use the status dropdown to show specific tasks.
  • Sort: Click column headers to cycle Asc / Desc / None.
  • Pagination: Use Prev / Next to navigate. Change page size to view more rows.
  • Inline status: Click the Status button in a row to advance it: TODO → IN_PROGRESS → DONE. A spinner shows while updating and the row is briefly highlighted on success.
  • Reset: Use Reset view or empty-state action to clear filters and sorting.

On small screens the guide moves below the table. Use the "Simulate load failure" checkbox to test error handling.
