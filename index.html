Usage Guide

Searching Tasks

Use the search box to find tasks by title. Matching keywords will be highlighted in the results.

Filtering & Sorting

Filter tasks by status using the dropdown. Click column headers to sort by that field. Click again to reverse sort, or a third time to clear sorting.

Updating Status

Hover over a task's status badge and click the next available status to update it inline. Status progression: TODO → IN_PROGRESS → DONE.

Pagination

Use the page size selector and navigation buttons to browse through tasks.

Task Details

Click on any task row to view full details in a modal dialog.

Reset View

Use the "Reset All" button to clear all filters, sorting, and return to the first page.
