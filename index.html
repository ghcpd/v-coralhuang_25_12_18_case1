📖 Usage Guide

🔍 Search Tasks

Type in the search box to find tasks by title. Matching keywords are highlighted.

🏷️ Filter & Sort

  • Status Filter: Select to show specific task statuses
  • Sort Headers: Click any column header to sort (asc/desc/none)

📄 Pagination

Navigate through pages and change page size using the controls below the table.

✅ Update Status

Click the "Next" button in the Status column to advance task status:

  • TODO → IN_PROGRESS
  • IN_PROGRESS → DONE

Tasks will briefly highlight after updates.

🔄 Reset View

Click the Reset button to clear all filters, sorting, and search.

💡 Tip: Click any task row to view full details in a modal.
